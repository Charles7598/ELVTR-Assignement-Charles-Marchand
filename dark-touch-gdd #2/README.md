# Dark Touch

A roguelike where a spectral dark-magic arm raises fallen enemies into your army, played with WoW-style GCD and rotation combat using aimed abilities. Built in Unreal Engine 5 for the ELVTR multi-agent AI course.

## Documents

The GDD exists in three versions, kept in sync: a 6-page version, a full reference version, and the canon for the AI agents.

Each document exists as Markdown (read on GitHub) and as PDF (download and print). Links in the PDFs open the sibling PDFs when the files are kept together in one folder.
